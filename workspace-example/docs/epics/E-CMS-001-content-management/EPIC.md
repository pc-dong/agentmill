## 1. 背景与业务动机

平台需要一个通用的结构化内容页能力：运营在 Console 按「内容类型 / 模板」组装内容页（如公告、帮助文档），通过可扩展的模块列表组合富文本、图片、视频等区块，发布后供 C 端（H5 / 小程序）查看，并可触达订阅用户。

本 Epic 将该配置能力沉淀为可对齐人与 AI 的产品分层规格，作为后续模块扩展与变更 PRD 的统一归属。

---

## 2. 业务目标与成功标准

### 2.1 目标

- 提供**模版化 / 模块化**的内容页配置能力。
- 支持两类内容：**公告**、**帮助文档**；对应两类默认模板。
- 内容配置由三块组成：**内容基本信息**、**展示配置（全局）**、**模块列表**（模块类型可迭代扩展）。

### 2.2 成功标准

| 编号 | 标准 | 衡量方式 |
|------|------|----------|
| GS-001 | 运营可在 Console 完成「基本信息 + 至少一个模块」的配置，并走通发布链路 | 定性验收：按主旅程走通创建→配置→发布 |
| GS-002 | 公告与帮助两类内容在配置侧可区分 | 定性验收：两类均可创建且默认模板可区分 |
| GS-003 | 新增模块类型时，不破坏既有内容配置与发布框架 | 定性验收：按 shared-context 登记 ModuleType 后可接入 |

## 3. 范围边界

### 3.1 包含（In）

- Console 侧内容的配置结构：基本信息、展示（全局）配置、模块列表。
- 内容类型：`ANNOUNCEMENT`（公告）、`HELP`（帮助文档）。
- 模块化框架：支持多种模块类型挂载到同一内容页；类型可扩展。
- 与发布 / 下线 / 删除相关的**框架级**约定（细则落在对应 PRD）。

### 3.2 不包含（Out）

- 单一模块的完整玩法细则（如测评、投票）→ 由独立模块 PRD 承载（可挂本 Epic 下）。
- 非内容页的其他运营位形态，除非作为模块引用。
- C 端页面的完整交互 / 视觉实现细节 → 另册；本 Epic 下属 PRD 仅写与配置对应的**关键 C 端验收要点**。

### 3.3 与相邻 Epic 的边界

- **框架类**（基本信息、展示配置、模块列表框架）PRD 必须挂本 Epic `E-CMS-001`。
- **大型模块增强**可独立建 Epic，但必须引用本目录 `shared-context.md`（权限码 / 对象 / `E-R-xxx`），不得另起冲突定义。
- 独立模块 Epic 应在本 Epic「下属 PRD 索引」或相邻边界中登记交叉链接，便于追溯。

## 4. 用户旅程

> 每步格式：角色 → 意图 → 触点/系统 → 可观察结果。

### 4.1 主旅程

1. 内容运营 → 创建内容并填写基本信息（标题、内容类型、时间等） → Console 内容管理 → 内容进入可编辑草稿 → 详见 P-001-01
2. 内容运营 → 配置分享文案、订阅开关等展示配置 → Console 展示/全局区 → 内容页级配置保存成功 → 详见 P-001-01
3. 内容运营 → 添加并编排模块（富文本、图片、视频等） → Console 模块列表 → 模块按顺序出现在配置中 → 详见 P-001-02
4. 内容运营 → 发布内容 → Console 发布 → 内容状态变为已发布；C 端按规则可访问（关键验收见 P-001-03）
5. C 端用户 → 打开内容页 → 客户端（H5 / 小程序） → 按模板与模块渲染页面；订阅用户收到更新通知

### 4.2 关键分支

1. 未持有内容管理权限码的用户进入详情 → 不可编辑或不可进入 → 详见权限码（shared-context §2 / §4）
2. 下线 → 状态变为已下线 → C 端不可再访问内容页（见 E-R-004 与 P-001-03）

  B --> C[模块列表]
  C --> D[发布]
  D --> E[C端内容页]

## 7. AI 消费提示

1. 先读本 Epic，再读同目录 `shared-context.md`，再读目标 PRD；未点名的 PRD 默认不读。
2. 实现时不得发明与 `shared-context.md` 中权限码 / 对象 / 术语冲突的新定义。
3. PRD 与 `shared-context.md` 冲突 → 停止实现，并在计划中记录冲突。
4. 仅当目标 PRD 声明了 `stories_appendix` 时才读取附录。
5. 不得根据 §4 旅程步骤自行补全 PRD 未写的业务规则。
6. 体系约定见 `docs/README-PRD体系.md`。
7. 实现前须确认目标 PRD 已 Ready；本 Epic 框架约定以本文与 `shared-context.md` 为准。
